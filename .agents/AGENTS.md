# 📜 REGRAS DO PROJETO - PEDE AQUI (TECX SOFTHOUSE)

## 📦 VERSIONEAMENTO E COMPILAÇÃO (OBRIGATÓRIO)
- **Sempre que for gerar um novo executável (.exe / build de produção)**:
  - **DEVE-SE OBRIGATORIAMENTE** incrementar a versão no `package.json` (ex: `1.0.0` -> `1.0.1`, `1.0.1` -> `1.0.2`) ANTES de compilar.
  - Nunca compilar um novo executável sem incrementar a versão no `package.json`.
  - Manter a regra de auto-update atualizada para envio à lanchonete/produção.
